# Le Bon Container — identité industrielle

Direction validée : orange industriel, inspiration sérigraphie. Conteneur anthropomorphe, visage navigateur, contours bleu nuit et typographie compacte. Aucun trait décoratif ni étincelle autour du personnage ou du texte. Les trois points du navigateur font partie du personnage.

## Palette

| Rôle | Couleur | Hex |
| --- | --- | --- |
| Accent et conteneur | Orange | `#EC5A13` |
| Contours, petits textes, fond sombre | Bleu nuit | `#18283B` |
| Fond clair et texte inversé | Crème | `#FFF4E4` |
| Ombres du conteneur | Orange profond | `#C9460E` |

Palette propre au projet, inspirée de l’univers des petites annonces. Ce ne sont pas des références officielles Leboncoin. Les images comportent des nuances de texture ; les codes ci-dessus servent aux éléments graphiques complémentaires. Petits textes : bleu nuit sur crème, ou crème sur bleu nuit.

## Typographie

Le logo possède un lettrage illustré, compact, épais et anguleux. Ce lettrage raster n’est pas une police livrée dans le kit.

Pour les futures compositions : Barlow Condensed ExtraBold pour les titres, Barlow Regular pour le texte, JetBrains Mono pour les légendes techniques. Ce sont des suggestions de complément, pas l’identification exacte du lettrage du logo. Les polices ne sont pas incluses. Les README conservent les polices de GitHub en dehors des images.

## Nom, ton et accroches

Nom affiché : **le bon container**. Nom de dépôt suggéré : `le-bon-container`.

FR : **Il a la tête de l’emploi.**

EN : **A browser with a head. A container with a purpose.**

FR : Un conteneur Docker pour explorer les annonces Leboncoin avec des agents IA, via un serveur MCP et Chromium en mode graphique.

EN : A Docker container for crawling Leboncoin with AI agents, through an MCP server and Chromium running in headed mode.

Signature technique : `MCP server · Headed Chromium · Docker`.

Voix : précise, accessible, avec un humour discret. Présenter les capacités réelles ; ne pas inventer de chiffres, badges de statut ou fonctions.

## Règles graphiques

- Préserver les proportions et les marges. Ne pas étirer les images.
- Garder au moins une hauteur d’œil autour du logo.
- Utiliser la mascotte seule pour les petits formats.
- Le logo transparent utilise du bleu nuit : privilégier un fond clair.
- Utiliser la bannière sombre sur fond sombre et la claire sur fond clair.
- Ne pas ajouter d’étincelles, de rayons ou d’effets lumineux.
- Garder les trois points du navigateur, les yeux et le sourire.
- Favoriser les fonds unis et les compositions graphiques simples.

## Livrables

Les images individuelles sont dans `assets/brand/` : `logo.png`, `avatar.png`, `banner-light.png`, `banner-dark.png`, `social-preview.png`. La planche validée est `direction-reference.png`.

`README-header.md` contient l’intégration bilingue ; `INTEGRATION.md` explique l’usage ; `brand-tokens.css` contient les couleurs et familles de caractères suggérées ; `ASSETS.txt` indique les dimensions réelles.

Ces visuels sont des PNG raster, et non des SVG vectoriels. Les variantes générées peuvent comporter de légères différences de dessin. Le kit ne définit pas la licence logicielle du projet.

Mention de contexte : « Projet indépendant, non affilié à Leboncoin. » / “Independent project, not affiliated with Leboncoin.”

## Méthode de création

Outil intégré de génération d’images, à partir de la planche industrielle validée. Consignes : conserver le personnage, les contours bleu nuit, l’orange, le fond crème et la typographie compacte ; décliner séparément en logo transparent, avatar, bannières claire et sombre, carte de partage. Aucun décor paysager, aucune étincelle. Trois points du navigateur conservés.
